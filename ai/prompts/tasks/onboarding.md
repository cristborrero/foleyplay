# Task: Onboarding Flow

## Goal
Get new users to experience value in under 60 seconds after registration.

## Steps
1. **Welcome** (step 1/4): "Bienvenido a FoleyPlay, [Name]". Single CTA: "Empezar".
2. **Preferences** (step 2/4): Pick 3+ genres from a grid of icons. Min selection required.
3. **Plan Selection** (step 3/4): Simplified 2-option pricing. Pre-select recommended plan.
4. **Ready** (step 4/4): Confetti animation. "Tu configuración está lista." CTA: "Explorar catálogo".

## Design
- Progress indicator at top (dots or numbered steps).
- Each step: centered, max-width 480px, vertically centered in viewport.
- Back button: visible but not prominent (ghost style).
- Skip option: only for optional steps (preferences).
- Animation: slide-in from right on advance, slide-in from left on back.

## Mobile
- Full-screen each step.
- Bottom-anchored CTA button (fixed to viewport bottom).
