# Reference: Linear Design System

## What to steal from Linear
- **Speed**: keyboard-first, instant feedback, optimistic updates everywhere.
- **Sidebar**: minimal, icon + label, collapsible, dark bg with hover states.
- **Command palette**: `⌘K` for everything. Power user friendly.
- **List views**: extremely compact, dense information without feeling cluttered.
- **Empty states**: illustration + headline + CTA. Consistent and delightful.

## Key Patterns
- Dark gray backgrounds (`#0f0f0f`, `#161618`), not pure black.
- Accent: purple/violet. But used minimally — mostly for active states.
- Micro-interactions on every click, hover, transition.
- Text: Inter, 13px for dense UI, 14px base.
- Icons: custom, consistent 1.5px stroke weight.

## Motion
- Page transitions: instant (no animation — Linear is FAST).
- Modals: 150ms fade + slight scale.
- Hover: 80ms ease — barely there but noticeable.
